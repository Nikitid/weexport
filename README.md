# WeExport updates for macOS

[Русский](README.ru.md)

[![Release](https://img.shields.io/github/v/release/Nikitid/weexport-updates)](https://github.com/Nikitid/weexport-updates/releases) [![License](https://img.shields.io/badge/license-MIT-blue)](LICENSE)

Public distribution of WeExport installers and signed updates.

## Features

Signed update feed, application archives, installers and checksums.

## Requirements

macOS 14 or later on Apple silicon.

## Installation

Download the installer from [Releases](https://github.com/Nikitid/weexport-updates/releases).

## Updates

Versions using the previous feed require one manual installation of a version configured for this repository.

## Development

Application source is maintained separately. This repository contains distribution metadata only.
